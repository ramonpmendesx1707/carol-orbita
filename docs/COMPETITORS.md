# Referências funcionais
Pesquisa em fontes oficiais em 06/10/2026. Três fabricantes/distribuidores relevantes, não ranking comprovado dos “três melhores”. Inspiração funcional sem copiar identidade.

Escolha: reduzir esforço do comprador técnico para selecionar, comparar e cotar. Não prometer estoque nem vender a preço fictício. CAD deve ser fornecido pelo fabricante, nunca gerado como arquivo comercial imaginário. Favoritos e rascunho de cotação reduzem repetição no retorno.

O projeto [RFK](https://github.com/ramonpmendesx1707/grupo-rfk) foi baixado separadamente: referência de mapa/rotas e estrutura institucional, com interface própria para catálogo industrial.
